# Nachkriegszeit

Lernmaterialien für den Leistungskurs Geschichte (Q2, Abitur 2027, Gymnasium NRW), Reihe „Die doppelte Staatsgründung 1949: geplantes Ziel oder ungewollte Folge der alliierten Deutschlandpolitik?“.

## Lernspiel „Vom Verbündeten zum Gegner“ (`spiel/`)

Entscheidungsspiel für eine EVA-Stunde (45 Minuten, Fortsetzung als Hausaufgabe). Die Schülerinnen und Schüler spielen zu zweit an einem Tablet die USA und die UdSSR und treffen in sieben Runden (1945–1949) verdeckt Entscheidungen:

1. Potsdam 1945: Reparationen
2. 1945/46: Umgestaltung der Zonen (Bodenreform, SED, Privateigentum)
3. 1946: Scheitern der Wirtschaftseinheit (Reparationsstopp, Byrnes, Molotow)
4. 1947: Truman-Doktrin, Marshall-Plan, Kominform
5. 1948: Markt oder Plan? (mit Sortierübung), Währungsreform
6. 1948/49: Berlin-Krise
7. 1949: Zwei Staaten

Nach jeder Runde zeigt das Spiel, wie die Gegenseite die Entscheidung deutete, einen Realitätscheck und die historische Entscheidung. Zwei Anzeigen verfolgen das Misstrauen zwischen Ost und West und die wirtschaftliche Einheit Deutschlands. Die Auswertung enthält einen Verlaufsvergleich mit der Geschichte, eine Einordnung in historiografische Deutungen und ein Urteil zur These vom Zerfall der Anti-Hitler-Koalition. Das Logbuch wird kopiert und in das OneNote-Kursnotizbuch eingefügt.

Der Spielstand wird nur im Browser des jeweiligen Geräts gespeichert.

Die Seite ist eine einzelne HTML-Datei ohne Build-Schritt und läuft über GitHub Pages.
